# Repository Instructions

- Treat `src/` as the source of truth for flow edits, docs, and manifest changes.
- Treat the top-level `windows-dev-config/`, `Workloads/`, and `wsl-comfort/` folders as generated release copies; do not edit them directly.
- Keep `src/manifest.yml` and `src/docs/development.md` aligned with any new or renamed flow.
